# Synthetic imaging report fixtures

Educational demo reports for MediGuide Imaging testing.
Not real patient data. Prefer the `.pdf` files for native-text extraction;
use the `.jpg` renders to exercise vision OCR on photo-like uploads.

| --- | --- |
| `mri-shoulder-right.pdf` / `.jpg` | MRI |
| `ct-chest-contrast.pdf` / `.jpg` | CT |
| `xray-chest-pa-lateral.pdf` / `.jpg` | X-ray |
| `ultrasound-abdomen.pdf` / `.jpg` | Ultrasound |
| `mri-brain-wo-contrast.pdf` / `.jpg` | MRI |
